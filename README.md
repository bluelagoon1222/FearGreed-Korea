# 공포·탐욕 CHECK (FearGreed-Korea)

지수가 아니라 종목 단위로 읽는 한국 주식시장 심리 대시보드.
저점을 찾는 **공포·탐욕 지수**(CNN 방식의 한국판)와 고점을 찾는 **과열도 지수**(자체 산출)를 나란히 두고,
종목 단위 시장 폭(breadth) 지표를 더했으며, 5년 히스토리를 3M · 6M · 1Y · 3Y · 5Y 버튼으로 KOSPI와 겹쳐 볼 수 있습니다.
GitHub Pages + GitHub Actions로 매 거래일 자동 갱신됩니다.

- 공개 주소: https://bluelagoon1222.github.io/FearGreed-Korea/
- 갱신 시각: 평일 18:20 KST(당일 종가), 다음날 07:20 KST(보정)
- 데이터: 네이버 금융(지수·종목·ETF 일별 시세, 시가총액 목록, 투자자별 매매동향), 금융투자협회(신용융자, 가용 시)
- 인증키 불필요

## 구성 지표 (8종, 0~100점, 종합 = 단순 평균)

| 지표 | 원자료 | 방향 |
|---|---|---|

| 주가 강도 | 유니버스 52주 신고가 비율 − 신저가 비율 (5일 평균) | 높을수록 탐욕 |
| 시장 폭 | 유니버스 상승 비율 − 하락 비율 (10일 평균) | 높을수록 탐욕 |
| 변동성 | VKOSPI (일별 자료 200일 이상 확보 시), 그 전에는 KOSPI 20일 실현변동성 | 높을수록 공포 (반전) |
| 안전자산 수요 | KOSPI 20일 수익률 − KODEX 국고채3년 20일 수익률 | 높을수록 탐욕 |
| 외국인 수급 | KOSPI 외국인 순매수 20일 누적 | 높을수록 탐욕 |
| 레버리지 선호 | 레버리지 ETF 거래대금 ÷ (레버리지+인버스), 5일 | 높을수록 탐욕 |
| 신용융자 (실험) | 신용거래융자 잔고 20일 변화율 | 높을수록 탐욕 |

차트용 시계열은 최근 1,250거래일(약 5년)을 싣고, 이를 위해 종목별 일별 시세는 7년치를 받습니다.
구간: 0~25 극단적 공포 / 25~45 공포 / 45~55 중립 / 55~75 탐욕 / 75~100 극단적 탐욕.

유니버스: KOSPI200 구성종목(네이버 편입종목 페이지, 실패 시 KOSPI 시총 상위 200) + KOSDAQ 시총 상위 150.
우선주(종목코드 끝자리 0이 아닌 것)·ETF·ETN·스팩·리츠는 제외합니다.

## 파일 구조

```
index.html                 대시보드 (data/latest.json을 읽어 그림)
scripts/collect.py         수집·계산 스크립트
scripts/requirements.txt   파이썬 패키지
data/latest.json           최신 스냅샷 + 250일 시계열 (Actions가 생성)
data/history.json          일별 누적 기록 (전종목 상승·하락 종목수 포함)
.github/workflows/update.yml   자동 실행 예약
```

## 설치 순서 (GitHub 웹에서)

1. 새 저장소 `FearGreed-Korea` 생성 (Public).
2. zip 안의 파일을 드래그 업로드 (`.github`, `.nojekyll`처럼 점(.)으로 시작하는 파일은 드래그에서 빠집니다).
3. 워크플로 파일은 아래 링크로 직접 생성:
   `https://github.com/bluelagoon1222/FearGreed-Korea/new/main?filename=.github/workflows/update.yml`
   → `.github/workflows/update.yml` 내용을 붙여 넣고 Commit.
4. Settings → Pages → Branch `main` / `(root)` → Save.
5. Actions → "Update Fear & Greed data" → Run workflow (첫 실행은 7년치를 받아 약 5~8분).
6. 실행이 끝나면 `data/latest.json`이 생기고 공개 주소에서 화면이 채워집니다.

|---|---|---|
| 장기 추세 이격 | KOSPI ÷ 200일 이동평균 − 1 | 3년 |
| 상승 속도 | KOSPI 60일 수익률 | 3년 |
| 상승장 변동성 | 변동성 백분위 × (60일 수익률 ÷ 10%, 0~1로 제한) — 하락 추세에서는 0 | 1년 |

| 레버리지 선호 | 레버리지 ETF 거래대금 비중 | 1년 |

두 지수의 조합으로 화면 상단에 참고 판독(공포+과열 해소, 탐욕+과열 등)을 표시합니다.

과거 고점(2021.1, 2024.7, 2026.2, 2026.6)과 저점(2022.10, 2024.8, 2025.4, 2026.3, 2026.7~8)에서의 두 지수 값을
매 실행마다 `data/status.json`과 화면의 "과거 고점·저점 검증" 표에 기록해, 지표를 바꿀 때 두 지수가 서로의 역할을 침범하지 않는지 확인합니다.

## 미국 Fear & Greed (CNN)

CNN Business가 공표하는 미국 Fear & Greed Index(0~100)를 매 실행마다 가져와 한국 게이지 옆에 나란히 보여주고,
히스토리 차트에 청록 선으로 겹칩니다. 미국 휴장일은 직전 값을 이어 쓰며, 받은 이력은 `data/us_feargreed.json`에 캐시합니다.

## 시장 폭 지표 (화면 상단 요약 타일 + 시장 폭 섹션)

- 전종목 상승·하락·보합 종목수 (KOSPI, KOSDAQ)
- 유니버스 350종목의 20·50·200일 이동평균 상회 비율
- 52주 신고가·신저가 종목수
- 누적 상승·하락선(ADL)과 KOSPI 비교

## 알려진 한계

- VKOSPI는 네이버 금융의 여러 경로(siseJson, 모바일 API, 일별 지수 페이지, 실시간 값)를 순서대로 시도합니다.
  일별 자료가 200일 이상 모이기 전까지는 실현변동성을 쓰고, 실시간 값만 받히는 경우 data/history.json에 매일 쌓아 자동 전환합니다.
- 오늘의 유니버스 구성으로 과거 7년을 계산하므로 과거로 갈수록 생존편향이 커지고, 상장 5년 미만 종목은 그 이전 구간 집계에서 빠짐.
- 장중 수동 실행 시 당일 값은 장중가.
- 금융투자협회 신용융자 조회가 막히는 날은 해당 지표만 자동 제외되고 나머지 7개로 종합지수 산출.
